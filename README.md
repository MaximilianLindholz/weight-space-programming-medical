# Weight-Space Programming for Medical Imaging: Do We Still Need Training Data?

[![arXiv](https://img.shields.io/badge/arXiv-2611.12066-b31b1b.svg)](https://arxiv.org/abs/2611.12066)

Code, LLM calls and results of the paper [arXiv:2611.12066](https://arxiv.org/abs/2611.12066).

Two LLMs, Claude Opus 5.5 and GPT-6 Astra, write all weights of a small CNN (ProgNet, 591 to 6,974 weights) in a
single reply, without tools and without seeing an image. Seven tasks: ChestMNIST, PneumoniaMNIST, BreastMNIST and
OrganA/C/SMNIST (MedMNIST v2), and SynthUterus (anteflexion vs retroflexion, synthetic uterine MRI). The written
networks are compared with MedSigLIP zero-shot and with the same network trained by Adam.

## Contents

| | |
|---|---|
| `runs/opus{1,2,3}/`, `runs/astra{1,2,3}/` | the 42 calls (3 per task and LLM): `prompt.txt`, `answer.md`, `thinking.md`, raw logs (`events.jsonl`; Astra also `request.json`, `response.json`), `run.json` (settings, usage, audit), `network.npz` (the written weights), `eval.json` (test AUC/ACC) |
| `checkpoints/` | Adam baselines: MedMNIST 256 labels and full data (seed 0), SynthUterus seeds 0-2 |
| `results/` | all results the paper reports, the MedSigLIP test subsets (`test_idx/`) and the SynthUterus split |
| `tables/`, `figs/` | Tab. 2, all numbers in the text (`numbers.tex`) and the figures, generated by `make_tables.py` and `figures.py` |

Code: `prognet.py` (network, data, metrics), `synthuterus.py` (case selection, de-duplication, split), `prompts.py`,
`edits.py` (parser for the written weights), `run_claude_code.py` and `run_openai.py` (the calls), `evaluate.py`,
`calls.py`, `adam.py`, `medsiglip.py`, `score_subset.py`, `evidence_maps.py`, `uterus_probe.py`, `agreement.py`,
`figures.py`, `make_tables.py`.

## Reproduce

```sh
pip install -r requirements.txt
./build.sh        # re-scores all written networks and checkpoints, writes results/, figs/, tables/
```

MedMNIST is downloaded to `data/` on first use. SynthUterus-ROI (Mueller et al. 2026,
[10.5281/zenodo.18587285](https://doi.org/10.5281/zenodo.18587285), CC BY 4.0) must be unpacked to
`data/SynthUterus-ROI/` (`images/`, `synthuterus-roi_annotations.parquet`); `python synthuterus.py` rebuilds
`results/uterus_split.csv`.

New calls: `WSP_RUNS=runs/opus4 python run_claude_code.py` (Claude Code headless, `--effort high`) or
`WSP_RUNS=runs/astra4 python run_openai.py` (API key in `OPENAI_API_KEY` or `~/.openai_api_key`, never in the
repository), then `python evaluate.py runs/<dir>`. Adam: `python adam.py train`. MedSigLIP: `python medsiglip.py`.
